# Internship Pipeline

Open dashboard.template.html to view the shareable dashboard without personal history. Run node refresh-dashboard.mjs to build dashboard.html from private/applications.md. Open dashboard.html for your personal view.

Keep your résumé, profile seed, and application history in private/. The generated dashboard embeds personal application records and is ignored by Git. Browser uploads and profile edits stay in browser storage. New résumé uploads require updating the profile fields if details changed.

The matching list is curated. It filters by published graduation windows and scores overlap with selected posting skills. Public board search is separate and unscored.

For Gmail sync, use the existing Codex Gmail connection to update private/applications.md and run the dashboard rebuild.

See plan.md and roadmap.md for project scope.
